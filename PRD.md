# PRD: StaffEfficiency — Дашборд эффективности администраторов ПК-клуба

## Цель
Автоматизированный инструмент для владельца и администраторов (3 филиала). Главная ценность — **автоматический расчёт бонуса за смену по выручке** + удобная инвентаризация магазина.

## Роли
- Владелец — полный доступ
- Старший администратор — управляет своим филиалом, обнуляет бонус
- Администратор — видит свои смены, задачи, заполняет «факт» остатков

## Главный KPI — Бонус за смену
Формула точно как в твоей Excel:
- Два плана: 15000 (день) и 5000 (ночь/доп)
- O = ROUND(SUM(выручка) / план * 100) - 100
- P = MIN(ROUND(O*10), 1000) или формула для второго плана
- Q = итоговый бонус (P + премия/штрафы)
- Если Q < 0 → кнопка «Обнулить» у старшего администратора

## Smartshell интеграция (автоматическая)
- GraphQL API[](https://apidoc.smartshell.gg)
- Автоматически подтягиваем: открытие/закрытие смен, выручку по тарифам, продажи товаров
- Администратор **не скачивает** файлы — всё приходит само

## Модуль «Инвентаризация магазина»
- Админ в конце смены вводит только колонку **«факт»** (остаток на полках)
- Приложение автоматически считает: разница, продано, доставлено, выставлено, склад (по твоим формулам)

## VK Bot
- Уведомления в личку или чат ВКонтакте: новая смена, новый бонус, напоминания, ежедневный отчёт
